# Учебные документы

Дневник `learning/LEARNING_DIARY.md` и дорожная карта `learning/ROADMAP.md`
являются единственным источником учебного состояния. Вариант регистра имени
`Roadmap.md` поддерживается; два файла, различающихся только регистром, вызывают
ошибку, чтобы приложение не выбирало документ молча.

«Успехи» читает файлы при открытии и по кнопке «Обновить». Вкладки документов
показывают полный исходный Markdown, включая произвольные разделы и историю.
Сводка вычисляется отдельно, без изменения документов: учитывает многострочные
пункты, отметки выполнения, блоки с произвольными заголовками. Неизвестные блоки
с чекбоксами входят в следующие шаги; полный документ всегда остаётся доступен.

Наставник в режимах «Курс», «Теория» и «Практика» читает инструкции проекта и
обновляет Markdown-файлы напрямую, сохраняя существующую структуру и записи.
Генератор интерактивных материалов только читает их. Собственные инструкции
проекта не перезаписываются при открытии. Новые документы создаёт наставник
после уточнения цели обучения; просмотр страницы ничего не создаёт в них.

Команды MCP `ronix_learning_*` сняты с регистрации. Старый HTTP-импорт возвращает
410 и больше не архивирует документы. SQLite продолжает обслуживать пользователей,
права, сессии, общую память и результаты интерактивных материалов. Старые учебные
таблицы сохранены для восстановления, но «Успехи» и наставник их не используют.

Для ранее импортированных проектов перед переключением остановите активные задачи,
сохраните копию БД и каталога learning, сравните записи после импорта с архивом.
Верните архивные документы в learning копированием, сохранив архив. Если после
импорта появились новые результаты, перенесите их в документы после сверки;
не заменяйте свежие файлы старым архивом. Обновите только относящиеся к хранению
пункты инструкций проекта. Резервная копия необходима для отката.
